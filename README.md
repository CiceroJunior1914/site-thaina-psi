# Site Thaina Psi

Site institucional para atendimento psicológico, desenvolvido em React com Vite, Tailwind CSS e animações com Framer Motion.

**Tecnologias:** React 19 · Vite · Tailwind CSS · Framer Motion

**Destaques**

⚡ Build rápido com Vite e HMR.

🎨 Interface responsiva estilizada com Tailwind CSS.

✨ Transições e animações suaves com Framer Motion.

## Como rodar localmente

`npm install`

`npm run dev`

## Build de produção

`npm run build`
